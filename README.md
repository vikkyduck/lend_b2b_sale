| Файл | Назначение |
|--|--|
| [`index.html`](index.html) | Главная — портфолио и услуги |
| [`webinar.html`](webinar.html) | Лендинг вебинара «B2B-внутрянка для экспертов», 29 мая |

## Стек

Статический HTML/CSS/JS, без сборщика. Открывается одним кликом, размещается на любом хостинге.

- Шрифты: Montserrat (sans), Fraunces (editorial italic) — через Google Fonts
- Фотография автора встроена inline (base64) в `webinar.html` и `thanks.html`
- Календарные кнопки строятся через `URLSearchParams` + Blob для `.ics`
