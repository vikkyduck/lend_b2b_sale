# vi-utkina.ru

Личный сайт Виктории Уткиной.

## Как устроено

Сайт статический. Страницы собирает один скрипт `build.py`: в нём лежат данные и шаблоны. Готовые страницы хранятся в репозитории рядом со скриптом.

| Что | Где |
|--|--|
| Кейсы и продукты | списки `CASES` и `PRODUCTS` в `build.py` |
| Названия продуктов, метки кейсов, заголовки страниц продуктов | только в `PRODUCTS` |
| Шапка, подвал, счётчик, значок | функция `page()` |
| Адреса страниц | функции `case_path()` и `product_path()` |
| Старые адреса и куда они ведут | словарь `REDIRECTS` |
| Тексты юридических документов | `content/legal/` |
| Отложенные материалы | `content/pending/` |
| Стили | `assets/css/style.css` |
| Старые страницы с Тильды | файлы `*.html` в корне, собраны вручную |

## Сборка

```
python3 build.py
```

Скрипт проверяет связи между данными и пересобирает страницы, карту сайта и `robots.txt`. Дата страницы в карте сайта берётся из git, поэтому правки коммитятся в день выката. Папка `content/` и сам скрипт на сайт не выкладываются.
